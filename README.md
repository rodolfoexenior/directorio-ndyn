# Directorio NDYN - Buscador Profesional

Este repositorio documenta el desarrollo de un buscador robusto construido desde cero en **Laravel 12**, marcando mi regreso al mundo de la programación tras 30 años de pausa.

## 🛠️ Stack Tecnológico y Entorno
- **Framework:** Laravel 12 (Última versión, entorno local vía Laragon)
- **Autenticación:** Laravel Breeze (Adaptado y forzado a **Bootstrap** para un diseño personalizado)
- **Frontend:** Bootstrap
- **Base de Datos & ORM:** Eloquent (Mapeo Objeto-Relacional para una gestión de datos profesional)
- **Estado del Proyecto:** 🚧 En Desarrollo (Entorno local de pruebas)

## 🎓 Metodología: Evolución Paso a Paso
Este proyecto es una bitácora de estudio intensivo. Iniciado **prácticamente desde cero**, el desarrollo se realiza bajo un esquema de aprendizaje guiado:
- **Estudio Asistido:** Mentoría técnica constante y revisión de lógica con **Gemini 3 Flash**.
- **Desarrollo Empírico:** Implementación manual de cada componente para garantizar el dominio total del framework.
- **Enfoque en Calidad:** Migración de lógica empírica hacia una arquitectura limpia en Laravel.
